# Phase 2 status - 2026-10-19

**State: in progress.** The Unity client has a playable 2-4 rider online prototype for Arena, Duel, and Grid Shift using the existing Node room service. Phase 0 physical-device validation and Phase 1 content/device work remain open. This is not the online MVP exit gate.

## Prototype decision

Use the existing dependency-free Node server for this prototype. It already owns browser room creation, six-digit online codes, a fixed-step authoritative match, input validation, results, and disconnect waiting. Unity sends input commands and renders server snapshots; `ArenaMatch` does not decide online outcomes. No new host, provider, account, database, or C# match server was added. A final Node-versus-C# server choice remains open until latency, capacity, and maintainability are measured.

The native client uses the server's JSON room API, an in-memory cookie jar for the temporary seat, and NDJSON snapshot streaming. The entered server origin must be HTTPS except for localhost testing. The setup screen defaults to the previously supplied Render origin, but its live reachability was not verified in this session and can be edited in the client. The Android build explicitly requests Internet permission.

## Implemented slice

- A separate online Unity scene supports create/join by six-digit room code, an Arena lobby for 2-4 riders (the host picks the size, then the map and persistent or fading walls), host start/pause/resume, live server riders/trails, relative turns, Auto Drive toggle, forward/fire holds, heat result, next heat, departure, and reconnection status. Unsupported modes, maps, seat counts, and wall rules display a clear leave-room message.
- The combined Phase 2 build starts at the offline Arena landing, opens Online Room, and can return to offline play after leaving a room. The Phase 1-only build hides the online link when the online scene is absent.
- The server remains authoritative. Unity does not advance local online collision, score, or pickup state.

## Reproduce locally

Build the desktop player from `android-game/` using pinned Unity with `-executeMethod GridRun.Editor.PhaseTwoBuild.BuildDesktop`, then run `android-game/scripts/Verify-Online.ps1 [-Seats 2|3|4] [-Mode arena|duel|shift]` from the repository root. The script uses a localhost-only online server, one hidden Unity player per seat, and ignored evidence (`artifacts/android-phase-2/final/` for two seats on Classic Grid with persistent walls; otherwise `final` plus `-<N>-seats`, `-<map>`, and `-fading` as they apply). Add `-Map solar|vault` and `-Rule decay` to choose the map and walls. The Android build command is `GridRun.Editor.PhaseTwoBuild.BuildAndroid`; its preview APK is ignored under `android-game/Builds/Android/` and is not the website download.
